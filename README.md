EcoCycle Solutions Website

Project Overview

EcoCycle Solutions is a responsive environmental awareness and recycling website designed to promote sustainable living practices within South African communities. The website provides information about recycling services, environmental workshops, educational resources, and community clean-up initiatives.

This project was developed as part of a web development assignment and demonstrates responsive web design principles using HTML and CSS.

Features

* Responsive website design
* Mobile, tablet, and desktop compatibility
* Professional navigation system
* External CSS styling
* Hover effects and animations
* Responsive images
* Booking and contact form
* Educational resources section
* Services showcase using card layouts
* Modern eco-friendly colour scheme

Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Media Queries

Pages Included

* Home Page
* About Us
* Services
* Resources
* Contact Page

Responsive Design

The website was tested using browser developer tools to ensure responsiveness across:

* Desktop devices
* Tablet devices
* Mobile devices

Responsive techniques implemented include:

* Media queries
* Flexible layouts
* Responsive images
* Grid and Flexbox layouts

Booking Functionality

The website includes a booking/contact form where users can:

* Enter their name and email
* Select a service
* Submit workshop or booking requests
* Provide additional information


Author

Amahle Myeni
