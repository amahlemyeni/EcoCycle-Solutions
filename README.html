Technical SEO

robots.txt

Instructs all crawlers to allow indexing; disallows /admin/ and /private/; includes Crawl-delay: 10; references sitemap.xml.

sitemap.xml

Lists all 6 pages with lastmod (2026-06-18), changefreq, and priority values. Conforms to sitemaps.org protocol.

Page Speed

Lazy loading on images; CDN-hosted Leaflet.js; all <script> tags placed at end of <body> (no render-blocking).

Accessibility (a11y)

Skip link; ARIA labels on interactive elements; role="alert" on error messages; aria-live on form responses; keyboard navigation throughout.

Part 3 Features — Forms

Enquiry Form (enquiry.html)

Purpose: Allow users to enquire about services, products, volunteer opportunities, or sponsorship. Displays a dynamic cost and availability response after submission.

Fields

First Name, Last Name, Email, Phone, Enquiry Type (service / volunteer / sponsor / product), Service Type (conditional), Preferred Date, Organisation, Message, Referral source.

Validation Rules

FieldRules
First / Last NameRequired; min 2 chars; max 50 chars
EmailRequired; valid email format (regex)
PhoneRequired; 7–15 digits/symbols regex
Enquiry TypeRequired; must select from dropdown
ServiceRequired only when Enquiry Type = "service"
DateOptional; must be a valid parsable date
MessageRequired; min 10 chars; max 1000 chars

Contact Form (contact.html)

Purpose: General messages, feedback, complaints, partnerships, and press enquiries. Compiles form data into a mailto: URI targeting takundajohnm@gmail.com.

Fields

First Name, Last Name, Email, Phone, Message Type (General / Feedback / Complaint / Partnership / Media / Other), Subject, Message, Privacy consent checkbox.

After Submission

  1. Form data is sanitised and compiled into a mailto: link with subject and body query parameters.
  2. A ticket ID (TKT-XXXXXXXXX) is displayed to the user.
  3. A button opens the user's default email client with the message pre-filled.
  4. The user sends the email directly — no server-side storage required.

Shared Validation System (js/forms.js)

  • Real-time validation on blur and change events
  • Red border + ARIA role="alert" error message below invalid fields
  • Green border on valid fields as positive feedback
  • Prevents submission if any field is invalid; focus moves to first error
  • Loading spinner on submit button during 1.2s async delay
  • Toast notifications for success and error states
  • escHtml() sanitises all user-generated content before DOM insertion
